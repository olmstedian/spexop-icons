# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-10-09

### 🎉 Initial Release

#### Added

##### **Core Package Features**

- Professional icon library with 262 carefully curated icons
- 17 comprehensive categories covering all common use cases
- Tree-shakeable ESM and CJS builds for optimal bundle size
- Full TypeScript support with type definitions
- Accessible components with ARIA attributes built-in
- Customizable size, color, and stroke width for all icons

##### **Icon Variants**

- 15 filled variants (heart, star, bookmark, circle, alerts, media controls)
- Support for all standard SVG props
- Consistent 24x24 viewBox with 2px stroke width
- Optimized SVG paths processed with SVGO

**Icon Categories** (262 total)

- Navigation & Arrows (27) - Directional icons including diagonal and circle variants
- Actions & Editing (16) - Common operations like copy, save, delete
- Communication (15) - Mail, messaging, phone, notifications
- Media & Entertainment (17) - Playback controls and media icons
- Files & Folders (13) - File management and cloud storage
- UI Controls (18) - Search, filter, settings, and interface elements
- Social & Community (20) - Sharing, reactions, and user management
- Commerce & Shopping (7) - Cart, payments, and e-commerce
- System & Status (25) - Alerts, loaders, and status indicators
- Forms & Input (7) - Authentication and form elements
- Layout & Structure (8) - Layout components and organization
- Devices & Technology (11) - Device types and connectivity
- Text & Typography (8) - Text formatting options
- Weather (10) - Complete weather icon set
- Development (11) - Git, terminal, debugging, and dev tools
- Tools & Utilities (20) - Miscellaneous helper icons
- Brand & Social Media (30) - Popular platforms (Facebook, Twitter/X, Instagram, LinkedIn, GitHub, Apple, Google, and more)

### **Developer Experience**

- Automated icon generation from SVG sources
- Comprehensive documentation suite
- Interactive showcase page with search and live preview
- GitHub Actions CI/CD workflows
- ESLint configuration with React best practices
- TypeScript strict mode enabled
- Example usage patterns and code samples

### **Documentation**

- README with complete usage guide
- GETTING_STARTED guide for setup
- CONTRIBUTING guidelines for contributors
- ICONS catalog with visual reference
- PACKAGE_SUMMARY with technical details
- CODE_OF_CONDUCT for community standards
- SECURITY policy for vulnerability reporting
- MIT License

###  **Technical Specifications**

- Package Size: 584KB uncompressed, ~17KB gzipped (tree-shaken)
- ESM Build: 57KB
- CJS Build: 67KB
- TypeScript Definitions: 34KB
- React Compatibility: >=16.8.0
- Build Tool: tsup with optimizations
- Package Manager: pnpm with frozen lockfile
