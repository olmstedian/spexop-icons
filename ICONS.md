## 🎨 Icon Features

### All Icons Support

- **Size**: Any px value or CSS unit
- **Color**: Any valid CSS color
- **Stroke Width**: Customizable (outline icons only)
- **Accessibility**: Title prop for screen readers
- **All SVG Props**: className, style, onClick, etc.

### Filled Variants (⭐)

15 icons have filled versions with `Filled` suffix:

- Heart, Star, Bookmark
- Circle, Square
- CheckCircle, XCircle, AlertCircle, AlertTriangle, Info
- Play, Pause, Stop
- ThumbsUp, ThumbsDown

## 📦 Usage Examples

### Basic Icons

```tsx
import { Home, User, Settings } from '@spexop/icons';

<Home />
<User size={32} />
<Settings color="#667eea" />
```

### Filled Variants

```tsx
import { Heart, HeartFilled, Star, StarFilled } from '@spexop/icons';

// Toggle between outline and filled
{isLiked ? <HeartFilled color="#ef4444" /> : <Heart />}
{rating >= 5 ? <StarFilled color="#f59e0b" /> : <Star />}
```

### Brand Icons

```tsx
import { Facebook, Twitter, Github, Linkedin } from '@spexop/icons';

<Facebook color="#1877F2" size={24} />
<Twitter color="#1DA1F2" size={24} />
<Github size={24} />
<Linkedin color="#0A66C2" size={24} />
```

### Custom Stroke Width

```tsx
import { Home } from '@spexop/icons';

<Home strokeWidth={1} />    // Thin
<Home strokeWidth={1.5} />  // Light
<Home strokeWidth={2} />    // Regular (default)
<Home strokeWidth={2.5} />  // Medium
<Home strokeWidth={3} />    // Bold
```

## 🔍 Icon Naming

All icons follow these conventions:

- **File names**: `kebab-case` (e.g., `arrow-right.svg`, `user-plus.svg`)
- **Component names**: `PascalCase` (e.g., `<ArrowRight />`, `<UserPlus />`)
- **Filled variants**: Add `Filled` suffix (e.g., `<HeartFilled />`, `<StarFilled />`)
